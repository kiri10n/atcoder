# atcoder

AtCoder Contest: https://atcoder.jp/home

## C++のインストール

コンパイラは既に入っている

```bash
gcc --version
g++ --version
```

コンパイル済みのファイルを実行するために以下を実行

```bash
sudo apt update
sudo apt upgrade
sudo apt install build-essential
```

## GitHub Copilot 自動補完の無効化

設定 > GitHub > Copilot > Enabled
cppを追加してfalseにしたらc++だけ補完されなくなる
